PS-text 图片编辑器  v1.0.0
轻量办公图片处理工具（Windows 7 SP1 及以上）

==============================  怎么用  ==============================

1. 双击「启动 PS-text.bat」。

   推荐用启动器，而不是直接双击 PS-text.exe —— 启动器会先检查运行环境，
   缺少 .NET Framework 4.8 时会给出中文提示和安装引导。

2. 想把 PS-text 加进图片的「打开方式」列表：

   菜单栏 -> 工具 -> 文件关联 -> 注册

   之后在任意图片上右键 ->「打开方式」就能看到 PS-text。
   说明：注册只写当前用户的注册表，不需要管理员权限；
        也不会改动你现有的默认打开程序。想设为默认，
        请点「打开系统的“设置默认程序”」自行选择。

==============================  运行要求  ==============================

- Windows 7 SP1 / 8 / 8.1 / 10 / 11
- .NET Framework 4.8 或更高

  Windows 7 与 Windows 8 通常需要自行安装：
  https://dotnet.microsoft.com/download/dotnet-framework/net48
  Windows 7 请选「4.8 运行时」，不要选 4.8.1 及以上（它们不支持 Win7）。

- 免安装：整个文件夹拷到哪都能用，不写系统目录，不需要管理员权限。
  唯一的例外是「文件关联」，它只写当前用户自己的注册表，依然不需要提权。

==============================  主要功能  ==============================

- 打开 / 编辑 / 另存为：JPG、PNG、BMP、GIF、TIFF
- 基础调整：亮度、对比度、饱和度、色温（拖动即时预览）
- 滤镜：反色、灰度、二值化、高斯模糊、USM 锐化
- 尺寸与角度：按像素 / 百分比 / 厘米缩放，任意角度旋转（可自动裁掉空白角）
- 修补 / 消除：智能填充（抹掉半透明文字水印、扫描件上的印章标记）、仿制图章
- 标注：箭头、矩形、椭圆、序号、高亮、文字 —— 非破坏性，随时可改参数
- 批量流水线：一套参数套到一批图上，导出为新文件，原文件不会被改动
- 打印：打印预览、DPI 感知、批量打印

==============================  快捷键  ==============================

Ctrl+O        打开
Ctrl+S        保存
Ctrl+Shift+S  另存为
Ctrl+Z        撤销
Ctrl+Y        重做
Ctrl+P        打印预览
Ctrl+0        适应窗口
Ctrl+1        原始大小
Ctrl+T        切换深色 / 浅色主题
空格          抓手工具（按住并拖动画布）

==============================  出问题了怎么办  ==============================

1. 菜单栏 -> 工具 -> 检测运行环境…    查看 .NET 版本、程序路径、日志目录
2. 菜单栏 -> 工具 -> 打开日志文件夹    把里面的日志发出来
   日志只在程序出错时才会写入，正常使用不会产生。

启动器也支持「只检测、不启动」（排查问题时用）：
   启动 PS-text.bat /check

==============================  命令行用法  ==============================

PS-text.exe --register        注册文件关联（无界面，适合部署脚本）
PS-text.exe --unregister      注销文件关联
PS-text.exe --assoc-status    查看当前关联状态
PS-text.exe --runtime         打印运行环境信息
PS-text.exe "D:\图片\a.jpg"   直接打开指定图片

==============================  关于本包  ==============================

- 免安装绿色版，不含 .NET Framework 安装程序（那会让包大上百倍）。
  推荐先用「启动 PS-text.bat」，它会检测并引导你安装。
  若需要完全离线部署，把 ndp48-x86-x64-allos-enu.exe 放进本文件夹，
  启动器会自动调用它。

- 本程序不采集、不上传任何数据，也没有任何联网行为。
